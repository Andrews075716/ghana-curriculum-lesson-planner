# ENGLISH LANGUAGE CURRICULUM FOR SECONDARY EDUCATION (SHS 1-3)

- **Source file:** curriculum-sources/English-Language-Curriculum.pdf
- **Subject:** English Language
- **Level/Form/Class coverage:** SHS 1-3 ("YEAR ONE", "YEAR TWO", "YEAR THREE")
- **Issuing authority:** National Council for Curriculum and Assessment (NaCCA), Ministry of Education, Republic of Ghana; Ghana Education Service also credited
- **Publication year/version:** September 2023
- **Document format:** PDF
- **Page count:** 217 (raw PDF page/form-feed count)
- **Apparent structure (hierarchy levels, in order, exact terminology):** Same Strand → Sub-Strand → Content Standard → Learning Outcome → Learning Indicator → Assessment shape as the science/technical subjects, but organised around **five fixed language-skill Strands repeated every year**, matching the pattern already seen in Arabic:
  1. **Strand 1. Oral Language** — Sub-Strands: English Speech Sounds, Listening Comprehension, Conversation/Communication (in Context)
  2. **Strand 2. Reading** — Sub-Strands: Reading Comprehension, Summarising
  3. **Strand 3. Grammar (Usage)** — Sub-Strands: Grammar (Usage), Vocabulary, and (Year 1 only) Punctuation and Capitalization
  4. **Strand 4. Writing** — Sub-Strands: Production and Distribution of Text, Text Types and Purposes, Building and Presenting Knowledge
  5. **Strand 5. Literature** — Sub-Strand: Narrative, Drama, Poetry (word order varies between "Poetry, Narrative and Drama" (Year 2 TOC) and "Narrative, Drama, Poetry" (Year 1/3 TOC) — a real source inconsistency, not an extraction artefact, confirmed by comparing multiple TOC entries)
  - Unlike Arabic (where sub-strand counts varied more sharply year to year, e.g. one year having zero sub-strands for a skill), English Language keeps a fairly stable 12-13 sub-strand set across all three years, with only "Punctuation and Capitalization" appearing solely in Year 1.
- **Curriculum code format:** `{Year}.{Strand}.{SubStrand}.{Type}.{Seq}`, e.g. `1.1.1.LO.1` — identical scheme to the science/technical subjects.
- **Category B elements present:**
  - [x] Core Competencies — folded into "21st Century Skills and Competencies" (e.g. "Communication and Collaboration", "Creativity and Innovation", "Critical thinking and Problem Solving")
  - [x] Values — "GESI¹, SEL² and Shared National Values" header, footnoted exactly like Chemistry/Computing/Agricultural Science/Agriculture
  - [x] GESI / [x] SEL / [x] 21st Century Skills — all present, same framework
  - [ ] Exemplars / Pedagogical guidance / Assessment guidance / Teaching and Learning Resources / Suggested Activities / National Values wording — not independently confirmed in the sampled pages (front matter + Scope and Sequence + first Learning Outcome block only); expected present by pattern but the CS/LI/Assessment table itself was not reached in this sample.
  - [x] Cross-Cutting Themes — generic front-matter references only, per pattern
- **Extraction feasibility:** COMPLETE for the sampled pages (native PDF text layer, no corruption observed).
- **Notes on anything unusual or differing from other subjects:**
  - Scope and Sequence (page 21) gives overall SHS 1-3 totals: **46 Content Standards, 58 Learning Outcomes, 102 Learning Indicators** — notably, Learning Outcomes (58) outnumber Content Standards (46) here, unlike every science/technical subject sampled so far where CS and LO counts were equal or close — meaning some Content Standards in this subject have multiple Learning Outcomes, a genuine one-to-many relationship the schema already supports but worth flagging as confirmed-in-use for this subject.
  - Front matter "Contextual Issues" (page 19) lists English-Language-specific implementation barriers in the Ghanaian context, including named misconceptions ("English Language is for girls", "It should not be studied because it is spoken by everybody") and "L1 interference in the learning of English" — same subject-specific contextual framing pattern seen in Arabic/Chemistry/Agricultural Science.
  - Same shared front-matter template (SHS Curriculum Overview, 21st Century Skills, GESI/SEL, Webb's DoK) as every other subject.
