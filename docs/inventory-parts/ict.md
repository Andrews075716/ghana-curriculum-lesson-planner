## Representative verbatim sample

Source: page(s) 25, 27 (printed page "INFORMATION COMMUNICATIONS TECHNOLOGY | 23" / "| 25"; PDF document index pages 25, 27), Strand 1 / Sub-Strand 1, Year One

```
Subject     INFORMATION AND COMMUNICATIONS TECHNOLOGY

Strand      1. ICTs IN THE SOCIETY
Sub-Strand  1. ORGANISING, MANAGING AND PRESENTING INFORMATION USING ESSENTIAL PRODUCTIVITY
               TOOLS

Learning Outcomes
1.1.1.LO.1
Create multimedia documents using appropriate computing tools

21st Century Skills and Competencies
Collaboration: Learners will work in mixed-ability/gender-sensitive groups (the
teacher identifies abilities and organises their seating), share their ideas with peers
and accept constructive feedback.

National core values: patriotism,
faithfulness, honesty, loyalty, discipline,
respect, humility, assertiveness, and
good citizenship.
```

```
Content Standards: 1.1.1.CS.1
Demonstrate knowledge and understanding of the use of various computing
tools to responsibly create multimedia documents containing text, images
etc. e.g., birthday cards/Flyers for a specified purpose

Learning Indicators and Pedagogical Exemplars with 21st Century and GESI: 1.1.1.LI.1
Describe software, hardware, and other computing features needed to
create a document.

Brainstorm and discuss: Using mixed-ability/gender-sensitive groups, discuss
computer hardware and software components required for creating multimedia
documents, addressing inclusivity and equity. For example, input devices that meet
learners with different abilities should be chosen, thus people with visual
impairment, dyslexia, dysgraphia.

Assessment: 1.1.1.AS.1
Level 1 Recall
Level 2 Skills of conceptual understanding
Level 3 Strategic reasoning
Level 4 Extended critical thinking and reasoning
```
