# LITERATURE-IN-ENGLISH CURRICULUM FOR SECONDARY EDUCATION (SHS 1-3)

- **Source file:** curriculum-sources/Literature-in-English-Curriculum.pdf
- **Subject:** Literature-in-English
- **Level/Form/Class coverage:** SHS 1-3 ("YEAR ONE", "YEAR TWO", "YEAR THREE")
- **Issuing authority:** National Council for Curriculum and Assessment (NaCCA), Ministry of Education, Republic of Ghana; Ghana Education Service also credited
- **Publication year/version:** Not independently re-confirmed on the cover page for this file (not in the sampled range); shared front-matter template implies September 2023.
- **Document format:** PDF
- **Page count:** 157 (raw PDF page/form-feed count)
- **Apparent structure (hierarchy levels, in order, exact terminology):** Same Strand → Sub-Strand → Content Standard → Learning Outcome → Learning Indicator → Assessment shape. Four genre-based Strands, with **Strand 1 appearing only in Year One**:
  1. **Strand 1. Exploring Literature** (Year 1 only) — Sub-Strand: General Knowledge in Literature
  2. **Strand 2. Prose** (every year) — Sub-Strands: Knowing your Narrative/Elements, Appreciation, From Narrative to Craft
  3. **Strand 3. Drama** (every year) — Sub-Strands: Knowing your Dramatic Elements, Appreciation, From Script to Stage
  4. **Strand 4. Poetry** (every year) — Sub-Strands: Knowing your Poetic Elements, Appreciation, From Verse to Performance
  - This is a hybrid pattern: mostly a fixed strand set repeated per year (like English Language/Geography/Government), but with one introductory Strand that only exists in Year 1 — a genuine structural variant not seen in exactly this form elsewhere, though closest to the "some sub-strands only in some years" pattern from Arabic/French.
- **Curriculum code format:** `{Year}.{Strand}.{SubStrand}.{Type}.{Seq}`, e.g. `1.1.1.LO.1` — identical scheme to every other subject.
- **Category B elements present:**
  - [x] Core Competencies — folded into "21st Century Skills and Competencies" (e.g. "Collaboration and Communication", "ICT Literacy", "Critical Thinking and Problem-Solving Skills")
  - [x] Values — "GESI¹, SEL² and Shared National Values" header, footnoted like other subjects; body text uses **"National Core Values:"** followed by an inline comma-separated list (e.g. "Tolerance, friendliness, open mindedness, patience, hard work, humility, respect for others.") rather than the bulleted list format used in Chemistry/Physics/Robotics — another confirmed formatting variance across subjects for the same conceptual field.
  - [x] GESI / [x] SEL / [x] 21st Century Skills — all present
  - [ ] Exemplars / Pedagogical guidance / Assessment guidance / Teaching and Learning Resources / Suggested Activities — not independently confirmed in the sampled pages; expected present by pattern.
- **Extraction feasibility:** COMPLETE for the sampled pages (native PDF text layer, clean, no corruption observed).
- **Notes on anything unusual or differing from other subjects:**
  - Front matter "Contextual Issues" (page 19) is subject-specific and candid about a real Ghanaian classroom perception problem: "Misconceptions and biases about the subject that Literature is for girls, perception as a difficult subject... learners not reading prescribed texts but rather commentary books" — same pattern of frank, subject-specific barriers as seen in Arabic, English Language, Chemistry, and Agricultural Science.
  - Scope and Sequence (page 21) gives overall totals: **39 Content Standards, 41 Learning Outcomes, 112 Learning Indicators**.
  - Same shared front-matter template (SHS Curriculum Overview, 21st Century Skills, GESI/SEL, Webb's DoK) as every other subject.
