# Ghana Curriculum Lesson Planner

A curriculum-first, AI-assisted lesson planning platform for teachers in Ghana. Teachers build lesson planners aligned to the official curriculum hierarchy (Subject → Class → Strand → Sub-Strand → Content Standard → Learning Outcome → Learning Indicator), which is stored as data and maintained by a curriculum administrator — never invented or altered by the application or by AI.

**Full documentation:** see [`docs/README.md`](docs/README.md) for the complete documentation set (product overview, requirements, architecture, database design, API reference, AI architecture and guardrails, security review, testing strategy, installation/deployment guides, roadmap, and current project status).

## Tech Stack

- [Next.js](https://nextjs.org) 16 (App Router) + TypeScript
- [Tailwind CSS](https://tailwindcss.com) v4 + [shadcn/ui](https://ui.shadcn.com)
- [PostgreSQL](https://www.postgresql.org) + [Prisma ORM](https://www.prisma.io)
- [Zod](https://zod.dev) for validation
- Custom session authentication (`jose` + `bcryptjs`) — not a third-party auth library
- Optional AI assistance via the Anthropic Claude API, behind a provider abstraction

See [`docs/06-system-architecture.md`](docs/06-system-architecture.md#15-technology-stack) for exact versions.

## Project Status

Authentication, curriculum administration (CRUD + CSV/JSON import), the 7-step lesson-planner wizard with autosave, AI-assisted planning suggestions, post-lesson reflection, and print/PDF export are all implemented and covered by an automated test suite. Several navigation items (My Planners list, planner detail view, curriculum browser, Classes, Resources, Assessments, and the public landing page) are placeholder pages only.

See [`docs/17-project-status.md`](docs/17-project-status.md) for the complete, evidence-based implemented/partial/not-implemented breakdown, and [`docs/14-development-roadmap.md`](docs/14-development-roadmap.md) for what's next.

## Getting Started

Full instructions: [`docs/12-installation-guide.md`](docs/12-installation-guide.md). Summary:

```bash
npm install
cp .env.example .env      # then fill in DATABASE_URL and generate a SESSION_SECRET
npm run db:local           # zero-install local PostgreSQL (separate terminal)
npx prisma migrate deploy
npm run db:seed
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Curriculum Data

Curriculum content (subjects, strands, sub-strands, content standards, learning outcomes, learning indicators) is stored in the database and managed independently of application code, through the curriculum administration area. It is never generated by the app or by AI. `docs/lesson plan.docx` is the reference sample used to design the data model and seed data — see [`docs/04-curriculum-architecture.md`](docs/04-curriculum-architecture.md).
